# Inpatient Patient Billing System

## Overview

This project calculates the total hospital bill for an inpatient.
An inpatient is a patient who stays in the hospital for one or more days.

The system uses three main pieces of information:

1. Patient name
2. Calculate fee
3. Room charge per day
4. Number of days

The system then calculates the patient's total bill.



## Patient Information

### Patient Name
**Naima**

### Patient Type
**Inpatient**

### Calculate Fee
**$30.0**

This is the basic fee charged for the inpatient.

### Room Charge Per Day
**$14.0**

This is the amount charged for the patient's room for each day.

### Number of Days
**50 days**

Naima stayed in the hospital for 50 days.



## Bill Calculation

The total inpatient bill is calculated using this formula:

```text
Total Bill = Calculate Fee + (Room Charge Per Day × Number of Days)




### Outpatient Patient Billing System

## Overview

This project calculates the total hospital bill for an outpatient.

An outpatient is a patient who visits the hospital or clinic for
medical services but does not stay in the hospital overnight.

In this example, the outpatient patient is **Aisha**.

The system uses two main charges:

1. Calculate Fee
2. Lab Charge

The system adds these charges together to calculate the patient's
total bill.



## Patient Information

### Patient Name

**Aisha**

The patient's name is Aisha.

### Patient Type

**Outpatient**

Aisha is an outpatient, which means she receives medical services
without being admitted to stay in the hospital.

### Calculate Fee

**$20.0**

This is the basic fee charged for the outpatient service.

### Lab Charge

**$7.0**

This is the charge for laboratory services or tests.



## Bill Calculation

The total outpatient bill is calculated using the following formula:

text
Total Bill = Calculate Fee + Lab Charge
